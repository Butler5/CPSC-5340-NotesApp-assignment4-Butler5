# Notes — iOS Application

A native iOS Notes application project built with Swift and Xcode. The repository contains the Xcode project, application source, and test targets.

## Technology

- Swift
- Xcode
- iOS SDK
- XCTest

## Run locally

1. Install Xcode on macOS.
2. Clone this repository.
3. Open `Notes/Notes.xcodeproj`.
4. Choose an iOS simulator or connected device.
5. Build and run the Notes target.

## Tests

The Xcode project includes unit-test and UI-test targets. Run them from Xcode's Test action after selecting the Notes scheme.
